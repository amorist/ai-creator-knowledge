## 为什么需要流水线

内容创作的真实瓶颈不是"写不出来"，是**每一步都在重新做决定**：今天写什么、从哪找素材、
什么角度、发出去怎么改。决定做得越晚、越多，产出就越靠情绪。

流水线的价值是：把决定**提前**，并且**落成文件**。决定一旦落成文件，下一次就是复用，
不再是重新拍脑袋。

## 五个阶段与各自的入库物

| 阶段 | 输入 | 动作 | 入库物（必须落文件） |
|---|---|---|---|
| 采集 | `feeds/` 订阅、随手收的链接 | 读、摘、标记价值 | `assets/` 里的素材卡（带来源链接） |
| 选题 | 素材卡 | 判断"值不值得做、给谁看" | `assets/选题库/` 里的选题卡（`status: develop`） |
| 深化 | 选题卡 | 找观点、找证据、找反例 | `learnings/` 里的经验条目（可复用结论） |
| 产出 | 深化结果 | 按平台写钩子与正文 | 成品稿（可在库外，但结论回填 `learnings/`） |
| 复盘 | 数据 + 成品 | 归因：哪一步错了 | `learnings/` 的经验更新（含反例） |

关键约束：**没有入库物的阶段等于没做**。采集完没素材卡，下周就找不到；产出完没回填，
这条经验只活在这一条内容里。

## 每一步的判据

**采集**——只收"能回答某个问题"的材料。判据：我能不能用一句话说出它证明了什么？
说不出就丢进 `_draft`，不要进 `assets/`。

**选题**——选题卡必须写清四件事：给谁、为什么现在做、角度是什么、需要什么素材。
缺任何一件，说明还没想清楚，先别深化。

**深化**——产物是**结论 + 证据 + 边界**。只写结论是口号，只写证据是资料，
没有边界是鸡汤（下次照抄必翻车）。

**产出**——同一份深化结果，按平台改钩子与节奏，不改结论。
如果为某个平台改了结论，说明这是另一个选题，回上一步。

**复盘**——先看"哪个阶段错了"，再看数据。完播低通常错在钩子（产出），
互动低通常错在选题（人群中不痛），涨粉低通常错在深化（没有可复用的结论）。

## 桌面工具如何接上

```
feeds/*.md  ──同步──▶  灵感面板（自动订阅 + 抓取）
                          │
                          ├─ 加入选题 ──▶ 选题库
                          └─ AI 翻译 / 改写 ──▶ 素材卡

知识库（本仓库） ──同步──▶ knowledge__recall 检索 / agent 读取 skills/
```

- **采集**：灵感面板读 `feeds/` 自动订阅，随手收的链接进「随手收」；
- **选题**：看到可用的文章直接「加入选题」，落到选题库；
- **深化 / 产出**：把 `skills/` 里的技能交给 agent（写作规范、平台格式、语气约束都在仓库里）；
- **复盘**：把结论写成 `learnings/` 条目并 push，下次 agent 检索时就会带上它。

## 反模式

- **靠对话当存储**：聊天记录不是知识库，不会在下次被检索到；
- **先写全文再想角度**：角度决定结构，顺序反了只能重写；
- **只沉淀爆款**：失败经验的边界信息更值钱，因为它告诉你"什么条件下不成立"；
- **把订阅当内容**：订阅是进水口，不生产内容；不读不摘，订阅就只是焦虑来源。
