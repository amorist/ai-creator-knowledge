# AI 内容创作 playbook

## 何时用

- 用户说「记录一个选题 / 帮我起个选题」「写口播 / 写小红书 / 写长文」「把这条拆一下」；
- 用户丢来一个链接、一段素材，说「存起来 / 这个能做什么内容」；
- 内容写完之后要「复盘 / 沉淀」。

## 输入

1. **知识库上下文**——先调用 `knowledge__recall` 检索相关经验与素材，别凭空开写；
2. **账号约束**——读 `profile/` 下的画像（受众、风格、禁区），它是唯一的约束来源；
3. **素材**——`feeds/` 订来的文章（`inspiration__read`），或用户直接给的链接。

## 步骤

1. **查**：`knowledge__recall({ query: <主题关键词>, domain: [...] })`。
   已有条目 → 更新；没有 → 新建。
2. **写选题卡**：落 `assets/选题库/<标题>.md`，四件事必须齐——
   给谁、为什么现在做、角度、需要什么素材；`status: develop`。
3. **深化**：结论 → 证据 → 怎么用 → **反例/边界**。缺边界的条目不允许入库。
4. **成稿**：按平台改钩子与节奏，不改结论。改结论 = 另起一个选题。
5. **回填**：把这次新学到的、可复用的结论写进 `learnings/`；
   引用外部来源必须在 `sources:` 或正文给出链接。

## 输出

- `assets/选题库/` 选题卡（或）
- `learnings/` 经验条目（或）
- 成品稿；结论必回填。

所有条目遵守 [SPEC.md](../../SPEC.md) 的 frontmatter 规范。

## 硬约束

- **不编造**数据、案例、引语、用户反馈；不确定就写"待验证"；
- 不用"赋能 / 闭环 / 发力 / 抓手"这类词；
- 一条经验只写一个结论，标题就是结论；
- 写完后自查：三个月后的自己，只看这一条能不能复用？

## 反例

- 把聊天记录当知识库：对话不会被检索到，等于没写；
- 先写全文再补角度：结构必然要重写；
- 只沉淀结论不写边界：下次照着用会翻车；
- 把订阅文章整篇搬进来：素材要摘成自己的话，并保留来源链接。
