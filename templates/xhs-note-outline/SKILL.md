# 小红书图文笔记骨架

## 何时用

用户说「写成小红书」「改成图文」「出个小红书版」，或选题卡 `domain` 命中小红书时。

## 输入

- 一条选题卡（`assets/选题库/*.md`，最好已完成深化）；
- 账号画像里的受众与禁区（`profile/`）。

## 骨架

| 张 | 作用 | 写法 |
|---|---|---|
| 封面 | 让人点开 | 一句话结论 + 一个具体数字/场景，≤ 20 字 |
| 1 | 提出处境 | 描述读者现在遇到的问题（说他的原话） |
| 2 | 反常识结论 | 和他预期相反的判断，一句话 |
| 3–5 | 给证据/步骤 | 一步一张，每张一个小标题 + 3 行内说明 |
| 6 | 反例 / 边界 | 什么情况下不适用（这条最能建立信任） |
| 7–8 | 行动与收拢 | 一个今天就能做的动作 + 一句总结 |
| 末 | 互动 | 一个具体问题（不要问"你怎么看"） |

## 硬约束

- 每张图**只讲一件事**，文字超过 3 行就拆成两张；
- 封面不出现"必看 / 速进 / 码住"这类无效词；
- 正文不出现无法核实的收益承诺（涨粉数、收入）；
- 所有外部事实配来源链接（写进 `sources:`，正文可不显示）。

## 输出

按上表输出 6–9 段，每段含：小标题、正文、如需配图的画面描述。

## 反例

- 封面是"AI 工具合集"却没有具体工具名——没有人会点；
- 把所有内容塞进一张长图——完读率归零；
- 只写好处不写边界——评论区第一条就是反驳。
